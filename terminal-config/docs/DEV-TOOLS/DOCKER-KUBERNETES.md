# 🐳 Docker & Kubernetes

## Docker Aliases

```bash
d               # docker
dc              # docker-compose
dps             # docker ps (pretty format)
dimg            # docker images
```

## K9s (Kubernetes TUI)

```bash
k               # k9s
k9              # k9s

# Install:
brew install k9s
```

## kubectl

```bash
# Tab completion with previews
kubectl get pods <TAB>
kubectl describe pod <TAB>
kubectl logs <TAB>
```

## Lazydocker

```bash
lzd             # lazydocker TUI
lazd            # Same thing

# Install:
brew install lazydocker
```
