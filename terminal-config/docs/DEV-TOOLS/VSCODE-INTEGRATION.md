# 💻 VSCode Integration

## VSCode Shortcuts

```bash
c               # code . (open current directory)
codehere        # Same as c
codediff file1 file2  # Compare files
```

## Examples

```bash
# Open project
cd ~/Projects/myapp
c

# Compare files
codediff old.js new.js

# Open specific file
code README.md
```

## Installation

```bash
# VSCode should install 'code' command automatically
# If not, open VSCode:
# Cmd+Shift+P → "Shell Command: Install 'code' command in PATH"
```
