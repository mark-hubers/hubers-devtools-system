# 🔧 Developer Utilities

## lazygit (Git TUI)

```bash
lg              # Open lazygit
lazg            # Same thing

# Install:
brew install lazygit
```

## lazydocker (Docker TUI)

```bash
lzd             # Open lazydocker
lazd            # Same thing

# Install:
brew install lazydocker
```

## httpie (Better curl)

```bash
GET https://api.example.com
POST https://api.example.com name=value
PUT https://api.example.com/1 name=newvalue
DELETE https://api.example.com/1

# Install:
brew install httpie
```

## tldr (Quick Examples)

```bash
tldr tar        # Show tar examples
tldr docker     # Show docker examples
help git        # Uses tldr

# Install:
brew install tldr
```
