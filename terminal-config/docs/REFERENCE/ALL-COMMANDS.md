# 📖 All Commands A-Z

Complete alphabetical list of all commands.

##  A-C

- `aws*` - AWS SSO commands (run `awshelp`)
- `bm` - Bookmark directory
- `bms` - List bookmarks
- `c` - Open VSCode in current dir
- `catp` - Plain cat (no formatting)
- `clip` - Copy to clipboard

## D-G

- `d` - Show zoxide history / docker
- `extract` - Extract any archive
- `gh*` - GitHub CLI commands (run `ghhelp`)
- `git-*` - Git utilities (git-undo, git-wip, git-cleanup)
- `grip` - Case-insensitive grep

## H-M

- `h` - Interactive history search
- `json` - JSON pretty print
- `k` - k9s (if installed)
- `killport` - Kill process on port
- `lg` - lazygit (if installed)
- `ltr` - List oldest→newest
- `mkcd` - Create dir and cd into it
- `mycd` - Jump to bookmark
- `myip` - Show local + public IP

## N-S

- `net*` - Network commands (run `nethelp`)
- `note` - Save quick note
- `notes` - View notes
- `path` - Show $PATH
- `port` - Check port usage
- `serve` - HTTP server

## T-Z

- `th` - Terminal help menu
- `tools` - Modern CLI tools reference
- `weather` - Show weather
- `z` - Smart directory jump

Run `th` for categorized help menu.
