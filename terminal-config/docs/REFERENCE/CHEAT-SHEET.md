# 📄 Quick Reference Cheat Sheet

## 🎯 Most Used (Start Here!)

```bash
# Directory Jumping
bm proj ~/Projects/myapp     # Bookmark
mycd proj                    # Jump
bms                          # List

# History
h                            # Search history

# Files
ltr                          # List oldest→newest
catp file                    # Plain cat
extract file.zip             # Extract anything

# Utilities
myip                         # Show IPs
port 8080                    # Check port
clip < file                  # Copy to clipboard
```

## 📚 Help System

```bash
th                           # Interactive menu
th <TAB>                     # All topics
th favorites                 # Customize startup
tools                        # Modern tools reference
```

## ⭐ Favorites (Startup Display)

```bash
fav                          # Show favorites
dev-tools                    # Same as fav
favedit                      # Edit favorites
dev-tools-edit               # Same as favedit
favoff                       # Disable at startup
favon                        # Enable at startup
```

## 🚀 Modern Tools

```bash
ls → ll, ltr, lsr
cat → catp, rawcat
grep → grip, grepi
cd → z, mycd, bm
```

## 💻 Development

```bash
gs, ga, gc, gp              # Git shortcuts
k                           # k9s
lg                          # lazygit
c                           # code .
```
